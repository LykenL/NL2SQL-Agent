# Frontend (V2)

This directory is reserved for the Next.js (React) frontend.

## Next Steps

When you're ready to initialize the UI, run the following commands inside this directory:

```bash
# 1. Initialize Next.js project (Use App Router, TypeScript, Tailwind)
npx create-next-app@latest .

# 2. Initialize shadcn/ui
npx shadcn-ui@latest init

# 3. Add base components
npx shadcn-ui@latest add button card input textarea scroll-area
```
